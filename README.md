# Denah Lab Biologi (3D)

Denah 3D interaktif laboratorium biologi berbasis Three.js.

Seluruh kode ada di satu file: `index.html`. Tidak perlu build atau instalasi.

## Cara menjalankan
Buka `index.html` di browser (butuh internet untuk memuat Three.js dan font dari CDN).

## Demo online
Aktifkan GitHub Pages di Settings → Pages → Branch `main` / folder `/ (root)`.
